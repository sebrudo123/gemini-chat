ℹ️ Cómo funciona

Este panel lee en tiempo real los canales y roles del servidor desde Discord. Cada cambio se guarda en la base de datos de Core IA y el bot lo aplica de inmediato en la siguiente interacción.

Los comandos /verificacion configurar, /verificacion panel, /verificacion estado y /verificacion desactivar también están disponibles dentro de Discord.
